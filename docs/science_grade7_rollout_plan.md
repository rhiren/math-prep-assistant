# Grade 7 Science Rollout Plan

This plan preserves the Grade 7 Science authoring method for the year. It is
intended to keep the course coherent as we add one concept pack at a time.

## Course Identity

- Subject: Science
- Course: Grade 7 Life Science
- Course id: `course-7-life-science`
- Local pathway: SRVUSD
- Standards framework: CA NGSS

The course follows the SRVUSD / California Grade 7 life-science emphasis:
cells, body systems, growth and reproduction, ecosystems, genetics, evolution,
and biodiversity / human impact.

## Design Rule

A Science concept is `Practice ready` only when it tests transfer, not just
recall.

Recall asks whether the learner remembers a word or fact. Transfer asks whether
the learner can use the idea when the surface details change. Science practice
should regularly ask the learner to reason from a scenario, model, diagram,
table, data pattern, evidence claim, or cause/effect chain.

## Tutorial Pattern

Each Grade 7 Science tutorial should use this structure:

1. Phenomenon or scenario first
2. Core idea
3. Model, system map, diagram thinking, or representation
4. Evidence rules
5. Common traps and misconceptions
6. Apply-it prompts

Keep tutorials concept-specific. Do not clone a generic tutorial body across
concepts with only the heading changed.

## Question Metadata

Science questions should use the existing `skillTags` plus Science-specific
`reasoningTags`.

Supported reasoning tags:

- `recall`
- `scenario-transfer`
- `claim-evidence`
- `model-interpretation`
- `cause-effect`
- `data-pattern`
- `misconception-check`

Use `recall` sparingly. A ready concept pack should not be vocabulary-only.

## Practice-Ready Checklist

Before a Grade 7 Science concept becomes learner-ready:

1. tutorial exists and follows the Science tutorial pattern
2. core test exists
3. review test exists
4. tests include multiple skill tags
5. tests include non-recall reasoning tags
6. tests include at least three Science reasoning forms across core + review
7. multiple-choice answer keys exactly match authored option values
8. scoring validation passes
9. concept has relevant CA NGSS tags
10. concept enters the active manifest as assessable

## Test Shape

Core tests should eventually contain 20-25 questions. Review tests should
eventually contain 15-20 questions. A smaller starter pack may be used only for
the first scaffold of a concept, but it should still include transfer,
evidence, model, and misconception reasoning.

Target mix for a full core test:

- 20-25% vocabulary or basic concept checks
- 25-30% scenario transfer
- 20-25% claim/evidence or explanation selection
- 15-20% model, diagram, or data interpretation
- 10-15% misconception or challenge reasoning

Target mix for a full review test:

- less isolated vocabulary than the core test
- more scenario transfer
- at least one mixed prior-concept connection when appropriate
- at least one question requiring evidence or model interpretation
