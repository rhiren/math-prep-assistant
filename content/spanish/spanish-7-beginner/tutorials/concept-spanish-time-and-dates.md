# Telling Time and Dates

## Hook

Time and dates show up everywhere in school Spanish: birthdays, schedules, calendars, and class routines.

## Big Idea

Spanish uses familiar number words plus a few sentence frames to tell dates and times.

Memory anchor: **Number words become calendar and clock words.**

## Learn It

Useful date words:

| Spanish | English |
|---|---|
| el día | the day |
| la fecha | the date |
| hoy | today |
| mañana | tomorrow |
| el cumpleaños | birthday |
| enero | January |
| febrero | February |
| marzo | March |
| abril | April |
| mayo | May |
| junio | June |
| julio | July |
| agosto | August |
| septiembre | September |
| octubre | October |
| noviembre | November |
| diciembre | December |

Date frames:

- ¿Cuál es la fecha? = What is the date?
- Hoy es el 15 de septiembre. = Today is September 15.
- Mi cumpleaños es el 26 de agosto. = My birthday is August 26.

Time frames:

- ¿Qué hora es? = What time is it?
- Es la una. = It is one o'clock.
- Son las dos. = It is two o'clock.
- Son las tres y media. = It is three thirty.
- La clase empieza a las ocho. = Class starts at eight.
- Tengo español a las nueve. = I have Spanish at nine.

## Build The Model

For dates:

`el + number + de + month`

Example:

`el 26 de agosto`

For time:

`Es la una` for 1:00.

`Son las + number` for most other hours.

Examples:

- `Es la una.`
- `Son las cuatro.`
- `Son las siete y media.`

## Memory Anchors

- **fecha** means date.
- Spanish dates use `de` between the day and month.
- **Es la una** is special because one o'clock is singular.
- Most other times use **Son las**.
- **a las** can mean at, as in a class time.

## Common Traps

- Trap: Translating dates in English order.  
  Fix: Use `el + day + de + month`.
- Trap: Saying `son las una`.  
  Fix: Use `Es la una`.
- Trap: Mixing `¿Qué hora es?` and `¿Cuál es la fecha?`  
  Fix: Time asks for the clock; date asks for the calendar.

## Pause And Think

- How do you say "What time is it?"
- What phrase means "What is the date?"
- Why is `Es la una` different from `Son las dos`?
- How would you say "August 26" in Spanish date order?
