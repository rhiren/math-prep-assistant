# Classroom Phrases

## Hook

The fastest way to feel less lost in Spanish class is to understand the phrases the teacher and students use every day.

## Big Idea

Classroom Spanish helps you participate before you know a lot of grammar. Useful phrases are tools for asking, answering, listening, and getting unstuck.

Memory anchor: **Classroom phrases keep you in the conversation.**

## Learn It

Start with phrases that solve real class problems:

| Spanish | English |
|---|---|
| No entiendo. | I do not understand. |
| Repita, por favor. | Repeat, please. |
| ¿Cómo se dice...? | How do you say...? |
| ¿Puedo ir al baño? | May I go to the bathroom? |
| Tengo una pregunta. | I have a question. |
| Gracias. | Thank you. |

Teachers may also use directions:

- Escuchen. = Listen.
- Repitan. = Repeat.
- Escriban. = Write.
- Lean. = Read.
- Contesten. = Answer.

## Build The Model

Use a classroom phrase when you need one of these actions:

`listen -> repeat -> ask -> answer -> clarify`

Example:

If the teacher gives a direction and you miss it, say: `Repita, por favor.`

## Memory Anchors

- **No entiendo** gets you help.
- **Por favor** and **gracias** make requests polite.
- **¿Cómo se dice...?** helps you grow vocabulary.

## Common Traps

- Trap: Staying silent when confused.  
  Fix: Use a help phrase.
- Trap: Translating every word before responding.  
  Fix: Memorize the whole phrase as one tool.
- Trap: Forgetting polite words.  
  Fix: Add `por favor` and `gracias` often.

## Pause And Think

- What phrase would you use if you did not understand?
- What phrase would you use to ask how to say a word?
- Which teacher direction means "listen"?

## Apply It

Choose two phrases to practice aloud today. Use them in class or while studying:

- `No entiendo.`
- `Repita, por favor.`
- `Tengo una pregunta.`
