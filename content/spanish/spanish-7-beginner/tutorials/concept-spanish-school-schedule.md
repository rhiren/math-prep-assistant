# School Subjects and Schedules

## Hook

A school schedule is one of the easiest real-life topics for Spanish class because you already know the world: classes, teachers, times, and opinions.

## Big Idea

Spanish school language helps you name classes, ask what class someone has, and describe a simple schedule.

Memory anchor: **Class + time + opinion makes a useful school sentence.**

## Learn It

Common school subjects:

| Spanish | English |
|---|---|
| el español | Spanish |
| las matemáticas | math |
| la ciencia | science |
| el inglés | English |
| la historia | history |
| la educación física | physical education |
| el arte | art |
| la música | music |

Useful schedule phrases:

- Tengo español. = I have Spanish.
- Mi clase favorita es ciencia. = My favorite class is science.
- ¿Qué clase tienes? = What class do you have?
- Tengo matemáticas a las nueve. = I have math at nine.

## Build The Model

Build a schedule sentence like this:

`Tengo -> class -> a las -> time`

Example:

`Tengo historia a las diez.`

## Memory Anchors

- **Tengo** can mean I have.
- **¿Qué clase tienes?** asks what class you have.
- **a las** introduces the time for many class schedules.

## Common Traps

- Trap: Forgetting articles like `la`, `el`, or `las`.  
  Fix: Learn class names with their articles.
- Trap: Using English word order for every sentence.  
  Fix: Practice whole sentence frames.
- Trap: Mixing `ciencia` and `ciencias`.  
  Fix: Use the term your teacher uses, and be consistent.

## Pause And Think

- How do you say "I have Spanish"?
- What phrase asks "What class do you have?"
- How would you say you have math at nine?

## Apply It

Write three class sentences:

- Tengo ____.
- Tengo ____ a las ____.
- Mi clase favorita es ____.
