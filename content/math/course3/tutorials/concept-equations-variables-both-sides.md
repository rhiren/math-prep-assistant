# Equations with Variables on Both Sides

## The big idea

Some equations have variable terms on both sides.

`5x + 3 = 2x + 18`

The goal is still to isolate the variable, but first move the variable terms
to one side.

Subtract `2x` from both sides:

`3x + 3 = 18`

Subtract 3:

`3x = 15`

Divide by 3:

`x = 5`

## Move variables first

A reliable first move is to collect variable terms on one side.

`7x - 4 = 3x + 16`

Subtract `3x` from both sides:

`4x - 4 = 16`

Add 4:

`4x = 20`

`x = 5`

You can move variables to either side, but choosing the side that keeps the
coefficient positive often makes the arithmetic easier.

## Then move constants

Once the variable terms are on one side, move constants to the other side.

`4x + 9 = x + 24`

Subtract `x`:

`3x + 9 = 24`

Subtract 9:

`3x = 15`

`x = 5`

## Watch subtraction and negatives

Negative coefficients are common when variables appear on both sides.

`2x - 7 = 5x + 8`

Subtract `2x` from both sides:

`-7 = 3x + 8`

Subtract 8:

`-15 = 3x`

`x = -5`

If the variable coefficient becomes negative, that is okay. Keep the balance
and divide carefully.

## Distribute first when needed

If either side has parentheses, distribute before moving terms.

`2(x + 4) = 5x - 7`

`2x + 8 = 5x - 7`

Subtract `2x`:

`8 = 3x - 7`

Add 7:

`15 = 3x`

`x = 5`

## Check in the original equation

Always check the answer in the original equation.

For `5x + 3 = 2x + 18`, if `x = 5`:

`5(5) + 3 = 28`

`2(5) + 18 = 28`

Both sides match, so `x = 5`.

## A reliable strategy

1. Distribute on either side if needed.
2. Move variable terms to one side.
3. Move constant terms to the other side.
4. Divide by the variable coefficient.
5. Check in the original equation.
