# Review Equivalent Expressions

## The big idea

Equivalent expressions may look different, but they have the same value for
every allowed value of the variable.

`3(x + 4)` and `3x + 12` are equivalent because distributing 3 gives the
same expression:

`3(x + 4) = 3x + 12`

Equivalent does not mean the expressions look identical. It means they always
match.

## Like terms

Like terms have the same variable part.

`4x` and `7x` are like terms.

`3a²` and `3a` are not like terms because the exponents are different.

To combine like terms, add or subtract only the coefficients.

`5x + 2x = 7x`

`8y - 3y = 5y`

Do not change the exponent when combining like terms.

`5x + 2x` is `7x`, not `7x²`.

## Constants stay with constants

Variable terms and constants are different kinds of terms.

`3x + 5 + 2x + 7`

Combine the `x`-terms:

`3x + 2x = 5x`

Combine the constants:

`5 + 7 = 12`

So:

`3x + 5 + 2x + 7 = 5x + 12`

## The distributive property

The distributive property lets a factor multiply every term inside parentheses.

`a(b + c) = ab + ac`

Examples:

`4(x + 3) = 4x + 12`

`5(y - 2) = 5y - 10`

The outside factor must multiply every term inside the parentheses.

## Negative signs and subtraction

Be careful when distributing a negative number or subtracting a group.

`-2(x - 5) = -2x + 10`

The product of `-2` and `-5` is positive `10`.

`3x - (x + 4) = 3x - x - 4 = 2x - 4`

Subtracting a group changes the sign of each term in the group.

## Factoring

Factoring reverses distribution.

`6x + 12 = 6(x + 2)`

Both terms share a factor of 6. Pulling out the shared factor makes the
equivalent expression `6(x + 2)`.

Factoring can reveal structure, such as equal groups:

`8x + 20 = 4(2x + 5)`

## Checking equivalence

Substituting one value can help catch mistakes, but one matching value does not
prove two expressions are equivalent.

To prove equivalence, use valid properties:

- combine like terms
- distribute
- factor
- rearrange terms using addition properties

Example:

`2(3x + 4) - x`

`= 6x + 8 - x`

`= 5x + 8`

So `2(3x + 4) - x` and `5x + 8` are equivalent.

## A reliable strategy

1. Identify like terms.
2. Distribute before combining across parentheses.
3. Track negative signs carefully.
4. Combine variable terms and constants separately.
5. Use substitution as a check, not as the only proof.
