# Translations on the Coordinate Plane

## Big Idea

A translation slides a point or figure without turning it, flipping it, stretching it, or shrinking it.

On the coordinate plane, every point moves the same horizontal amount and the same vertical amount. If point `A` moves 4 units right and 3 units down, then every other point in the figure also moves 4 units right and 3 units down.

That is why translations are called rigid transformations. The figure changes location, but its size and shape stay the same.

## What To Notice

- Moving right adds to the `x`-coordinate.
- Moving left subtracts from the `x`-coordinate.
- Moving up adds to the `y`-coordinate.
- Moving down subtracts from the `y`-coordinate.
- A translation vector such as `<4, -3>` means add 4 to `x` and subtract 3 from `y`.
- A coordinate rule such as `(x, y) -> (x + 4, y - 3)` describes the same move.
- Every point in the figure must follow the same rule.

## Worked Example

Point `A` is at `(-2, 5)`. Translate it 6 units right and 4 units down.

Right 6 means add 6 to the `x`-coordinate:

`-2 + 6 = 4`

Down 4 means subtract 4 from the `y`-coordinate:

`5 - 4 = 1`

So the image point is `A'(4, 1)`.

The same move can also be written as vector `<6, -4>` or as the coordinate rule:

`(x, y) -> (x + 6, y - 4)`

## Strategy

| Task | What to do |
| --- | --- |
| Find the image of a point | Add the translation vector to the coordinates. |
| Find the vector from preimage to image | Subtract starting coordinates from ending coordinates. |
| Find the preimage | Work backward by subtracting the translation vector from the image. |
| Translate a figure | Translate each vertex by the same vector. |
| Check a translation | Distances, angles, side lengths, and orientation should stay the same. |

## Memory Anchors

Think of a translation as a slide.

If the vector is `<a, b>`, then:

`(x, y) -> (x + a, y + b)`

The first number controls left or right. The second number controls up or down.

Positive `x` moves right. Negative `x` moves left. Positive `y` moves up. Negative `y` moves down.

## Common Traps

- Do not switch the two numbers in the vector. `<5, -2>` is not the same as `<-2, 5>`.
- Do not change only one point in a figure. Every vertex must move the same way.
- Do not reverse the signs unless you are intentionally working backward.
- Do not confuse a translation with a reflection. A translation slides the figure; it does not mirror it.
- Do not assume the figure must move into Quadrant I. Translations can move through any quadrant.

## Pause And Think

Suppose point `B(-3, -1)` is translated by vector `<5, 4>`.

The new `x`-coordinate is `-3 + 5 = 2`.

The new `y`-coordinate is `-1 + 4 = 3`.

So `B'` is `(2, 3)`.

Now reverse it. If `B'` is `(2, 3)` and the vector was `<5, 4>`, then the original point was:

`(2 - 5, 3 - 4) = (-3, -1)`

Working backward is useful when a question gives the image and asks for the preimage.

## Apply It

A triangle has vertices `P(1, 2)`, `Q(5, 2)`, and `R(3, 6)`. Translate the triangle by `<-4, 3>`.

Move each point left 4 and up 3:

- `P(1, 2) -> P'(-3, 5)`
- `Q(5, 2) -> Q'(1, 5)`
- `R(3, 6) -> R'(-1, 9)`

The triangle slid to a new location. The side lengths and angle measures did not change.

## 3-2-1 Memory Check

3 things to remember:

- A translation is a slide.
- The same vector applies to every point.
- `<a, b>` means add `a` to `x` and add `b` to `y`.

2 signs to watch:

- Right and up are positive.
- Left and down are negative.

1 question to ask yourself:

Did I change every point by the exact same horizontal and vertical amounts?
