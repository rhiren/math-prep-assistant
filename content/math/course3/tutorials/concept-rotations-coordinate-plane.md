# Rotations on the Coordinate Plane

## Big Idea

A rotation turns a point or figure around a fixed point called the center of rotation.

In this lesson, the center is the origin, (0, 0). A rotation can be a quarter-turn, a half-turn, clockwise, or counterclockwise. The point moves to a new location, but it stays the same distance from the origin.

Rotations are rigid transformations. The image may face a new direction, but side lengths, angle measures, and overall shape stay the same.

## What To Notice

- A 90 degree counterclockwise rotation uses (x, y) -> (-y, x).
- A 90 degree clockwise rotation uses (x, y) -> (y, -x).
- A 180 degree rotation uses (x, y) -> (-x, -y).
- The center of rotation is the point that the figure turns around.
- For rotations about the origin, the distance from each point to the origin stays the same.
- A full figure rotates by moving every vertex with the same rotation rule.

## Worked Example

Rotate point A(3, 5) 90 degrees counterclockwise about the origin.

Use the rule:

(x, y) -> (-y, x)

The original point has x = 3 and y = 5.

The new first coordinate is -y, so it is -5.

The new second coordinate is x, so it is 3.

So the image is A'(-5, 3).

## Strategy

| Rotation about the origin | Coordinate rule | Quick check |
| --- | --- | --- |
| 90 degrees counterclockwise | (x, y) -> (-y, x) | swap coordinates, then make the new x negative |
| 90 degrees clockwise | (x, y) -> (y, -x) | swap coordinates, then make the new y negative |
| 180 degrees | (x, y) -> (-x, -y) | change both signs |

For a polygon, rotate each vertex. Then connect the image vertices in the same order.

## Memory Anchors

A 90 degree rotation swaps the coordinate positions.

A 180 degree rotation does not swap positions. It changes both signs.

Clockwise and counterclockwise quarter-turns undo each other:

- 90 degrees clockwise, then 90 degrees counterclockwise, lands back at the original point.
- Two 90 degree turns in the same direction make a 180 degree turn.

## Common Traps

- Do not use the reflection rules. A rotation is a turn, not a mirror flip.
- Do not change only one coordinate for a 90 degree rotation. Quarter-turns swap coordinate positions.
- Do not mix up clockwise and counterclockwise. (x, y) -> (-y, x) is counterclockwise; (x, y) -> (y, -x) is clockwise.
- Do not rotate just one vertex of a figure. Every vertex must follow the same rotation rule.
- Do not assume the figure changes size. Rotations preserve distance and angle measure.

## Pause And Think

Rotate B(-4, 2) 90 degrees clockwise about the origin.

Use (x, y) -> (y, -x).

The new first coordinate is the old y: 2.

The new second coordinate is the opposite of the old x: 4.

So B'(2, 4).

Now reverse it. If a point is rotated 90 degrees clockwise, then a 90 degree counterclockwise rotation takes it back to where it started.

## Apply It

Triangle PQR has vertices P(1, 2), Q(4, 2), and R(2, 5). Rotate the triangle 90 degrees counterclockwise about the origin.

Use (x, y) -> (-y, x) for every vertex:

- P(1, 2) -> P'(-2, 1)
- Q(4, 2) -> Q'(-2, 4)
- R(2, 5) -> R'(-5, 2)

The triangle has turned around the origin. The side lengths and angle measures are unchanged.

## 3-2-1 Memory Check

- 90 degrees counterclockwise: (x, y) -> (-y, x)
- 90 degrees clockwise: (x, y) -> (y, -x)
- 180 degrees: (x, y) -> (-x, -y)

2 things rotations preserve:

- distance
- angle measure

1 question to ask yourself:

Which turn am I making: clockwise, counterclockwise, or 180 degrees?
