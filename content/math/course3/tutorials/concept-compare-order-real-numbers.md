# Compare and Order Real Numbers

## The big idea

Every real number has one position on the number line. To compare or order
real numbers, rewrite them in forms that make their positions easy to see.

A list may mix:

- integers
- fractions
- terminating or repeating decimals
- square roots
- cube roots
- constants such as `π`

The goal is not to change the exact numbers. The goal is to find reliable
benchmarks that reveal their order.

## Comparison symbols

- `a < b` means `a` is less than `b`.
- `a > b` means `a` is greater than `b`.
- `a = b` means the two expressions name the same exact value.

On a number line, values farther right are greater.

## Simplify exact values first

Before estimating, check whether a radical has an exact rational value.

- `√49 = 7`
- `-√81 = -9`
- `∛(-64) = -4`

For example, compare `√49` and `6.9`:

`√49 = 7`

Therefore:

`√49 > 6.9`

Exact simplification is stronger and faster than rounding.

## Convert rational numbers to a useful form

Fractions are often easiest to compare as decimals or equivalent fractions.

Compare `5/8` and `0.6`:

`5/8 = 0.625`

Therefore:

`5/8 > 0.6`

Some representations are exactly equal:

`3/4 = 0.75`

Use `=` when the values are exact equivalents.

## Bound irrational square roots

Use nearby perfect squares.

Compare `√30` and `5.4`:

`5.4² = 29.16`

Since `29.16 < 30`:

`5.4 < √30`

To order `5.4`, `√30`, and `5.5`, also check:

`5.5² = 30.25`

Therefore:

`5.4 < √30 < 5.5`

## Compare positive square roots without decimals

For nonnegative numbers, the square-root function preserves order.

Because:

`11 < 13`

we know:

`√11 < √13`

You do not need decimal approximations when both radicands are already easy to
compare.

## Compare cube roots

Cube roots also preserve order for all real numbers.

Since:

`50 < 70`

then:

`∛50 < ∛70`

This works with negative values too:

`-100 < -60`

so:

`∛(-100) < ∛(-60)`

## Handle negative numbers carefully

Among negative numbers, the value with the greater absolute value lies farther
left and is smaller.

Compare `-√10` and `-3.1`:

`√10 ≈ 3.162`

so:

`-√10 ≈ -3.162`

Therefore:

`-√10 < -3.1`

The inequality reverses when both positive values are multiplied by `-1`.

## Order mixed real numbers

Use one common comparison form.

Order `-2.6`, `-√7`, `-5/2`, and `-2.4`.

Convert or approximate:

- `-√7 ≈ -2.646`
- `-2.6 = -2.600`
- `-5/2 = -2.5`
- `-2.4 = -2.400`

From least to greatest:

`-√7 < -2.6 < -5/2 < -2.4`

For negative decimals, compare from the left side of the number line rather
than choosing the value with the smaller-looking digits.

## Compare numbers involving π

Use enough digits for the decision:

`π ≈ 3.14159`

Compare `π` and `3.14`:

`π > 3.14`

Compare `π` and `22/7`:

`22/7 ≈ 3.142857`

Therefore:

`π < 22/7`

The fraction `22/7` is a useful approximation, but it is not exactly equal to
`π`.

## Choose useful precision

Approximate only as far as needed to separate the values.

To compare `√2` and `1.42`:

`√2 ≈ 1.414`

Three decimal places are enough:

`√2 < 1.42`

Rounding `√2` to the nearest tenth would give `1.4`, which is less precise but
still sufficient here. When values are very close, keep more digits.

## Compare expressions

Evaluate or estimate each complete expression before comparing.

Compare `2 + √3` and `3.7`:

`2 + √3 ≈ 2 + 1.732 = 3.732`

Therefore:

`2 + √3 > 3.7`

Do not compare only the radical part and ignore the rest of the expression.

## A reliable ordering strategy

1. Simplify perfect-square and perfect-cube roots exactly.
2. Convert fractions or repeating decimals when helpful.
3. Bound irrational roots with nearby squares or cubes.
4. Approximate only to the precision needed.
5. Mark each value on an imagined number line.
6. Read from left to right for least to greatest.
7. Substitute your ordered values back into the original forms.

## Common mistakes

- Assuming every radical is irrational. `√64 = 8`.
- Treating an approximation as exact. `π ≈ 3.14`, but `π ≠ 3.14`.
- Forgetting that `-3.5 < -3.2`.
- Comparing unlike forms by their visible digits, such as saying `√20 > 10`
  because `20 > 10`.
- Rounding too early when values are close.
- Losing a negative sign while simplifying `-√a`.
- Ordering the decimal approximations correctly but copying the original
  expressions back in the wrong order.

## Quick practice

1. Compare `√18` and `4.2`.
2. Compare `-√5` and `-2.2`.
3. Order `3.1`, `π`, and `√10` from least to greatest.
4. Order `-3/2`, `-√2`, `-1.4`, and `0`.
5. Which is greater: `2 + √5` or `4.2`?

### Answers

1. `√18 > 4.2` because `4.2² = 17.64 < 18`.
2. `-√5 < -2.2` because `-√5 ≈ -2.236`.
3. `3.1 < π < √10`
4. `-3/2 < -√2 < -1.4 < 0`
5. `2 + √5 > 4.2` because `2 + √5 ≈ 4.236`.
