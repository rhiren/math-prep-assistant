# Rational and Irrational Numbers

## 1. What is this concept?

Every number on the number line is a **real number**.

Real numbers can be divided into two groups:

- **rational numbers**
- **irrational numbers**

For example, `3/4` of a cup is rational. The number `π`, which is used to
measure circles, is irrational.

## 2. What does it mean?

A rational number can be written as a fraction:

`a/b`

where `a` and `b` are integers and `b` is not zero.

The word *rational* is connected to the word *ratio*. A fraction is a ratio of
two integers.

An irrational number cannot be written as a fraction of two integers. Its
decimal digits continue forever without ending or settling into a repeating
pattern.

## 3. Key Ideas

- Integers are rational because any integer can be written over `1`. For
  example, `-6 = -6/1`.
- Terminating decimals are rational. For example, `0.45 = 45/100`.
- Repeating decimals are rational. For example, `0.333... = 1/3`.
- A square root of a perfect square is rational. For example, `√49 = 7`.
- A square root of a positive integer that is not a perfect square is
  irrational. For example, `√10` is irrational.
- `π` is irrational.

## 4. How to Classify a Number

1. Simplify the number if possible.
2. Ask whether it is an integer or fraction.
3. If it is a decimal, decide whether it terminates or repeats.
4. If it contains a square root, check whether the number under the radical is
   a perfect square.
5. Classify the simplified value, not just the way the original expression
   looks.

## 5. Why This Works

Think of rational numbers as numbers that can be built from an exact fraction.

Terminating decimals can be placed over a power of ten. Repeating decimals can
also be converted into fractions using algebra. That is why both types are
rational.

Irrational decimals never terminate and never repeat. No fraction of integers
can produce that kind of decimal pattern.

The fraction test is the final test:

> Can the exact value be written as one integer divided by another nonzero
> integer?

## 6. Common Mistakes

- **Thinking every square root is irrational.**
  `√64` equals `8`, so it is rational.

- **Thinking every long decimal is irrational.**
  A decimal such as `0.121212...` repeats, so it is rational.

- **Classifying an expression before simplifying it.**
  The expression `√9 + √2` contains one rational part and one irrational part,
  but its total value is irrational.

- **Assuming `π` means `3.14` exactly.**
  `3.14` is a rational approximation. The exact value `π` is irrational.

- **Forgetting that integers are fractions.**
  The integer `5` can be written as `5/1`.

## 7. Examples

### Example 1 — Terminating decimal

Classify `0.625`.

1. The decimal terminates.
2. Write it as a fraction: `625/1000`.
3. Simplify: `625/1000 = 5/8`.

**Answer:** `0.625` is rational.

### Example 2 — Square root

Classify `√81`.

1. Check whether `81` is a perfect square.
2. Since `9 × 9 = 81`, `√81 = 9`.
3. The integer `9` equals `9/1`.

**Answer:** `√81` is rational.

### Example 3 — A common trap

Classify `0.101001000100001...`.

The groups of zeros keep getting longer. The digits do not settle into one
repeating block.

**Answer:** The number is irrational.

## 8. Real-Life Connection

Suppose a square garden has an area of `2` square meters.

Its exact side length is `√2` meters. Because `2` is not a perfect square,
`√2` is irrational. A builder may use `1.414` meters as a practical
approximation, but that decimal is not the exact value.
