# Approximate Irrational Numbers

## The big idea

An irrational number cannot be written as an exact terminating or repeating
decimal. Its digits continue forever without repeating a fixed block.

That does **not** mean we cannot locate or use it. We can place an irrational
number between rational benchmarks and approximate it as precisely as a
problem requires.

For example:

`2² = 4` and `3² = 9`

Because `5` lies between `4` and `9`:

`2 < √5 < 3`

The exact value is still `√5`. The decimal `2.236...` is an approximation.

## Exact values and approximations

Use the equal sign only when two values are exactly equal:

`√49 = 7`

Use the approximation symbol when digits have been rounded:

`√5 ≈ 2.24`

The value `2.24` is rational because it terminates. It is close to `√5`, but
it is not equal to `√5`.

## Step 1: Find whole-number bounds

Use the perfect squares on either side of the radicand.

To locate `√30`:

`25 < 30 < 36`

Take the square root of each part:

`5 < √30 < 6`

This places `√30` between `5` and `6` on a number line.

| Radicand | Nearby perfect squares | Root bounds |
| --- | --- | --- |
| 7 | `4 < 7 < 9` | `2 < √7 < 3` |
| 40 | `36 < 40 < 49` | `6 < √40 < 7` |
| 90 | `81 < 90 < 100` | `9 < √90 < 10` |
| 170 | `169 < 170 < 196` | `13 < √170 < 14` |

## Step 2: Narrow the interval with tenths

To approximate `√30` to the nearest tenth, test decimal values between `5`
and `6`.

- `5.4² = 29.16`
- `5.5² = 30.25`

Therefore:

`5.4 < √30 < 5.5`

The actual value is about `5.477...`, so:

`√30 ≈ 5.5` to the nearest tenth.

Squaring the decimal benchmarks tells you whether each one belongs below or
above the root.

## Step 3: Use hundredths when needed

Suppose we need `√7` to the nearest hundredth.

- `2.64² = 6.9696`
- `2.65² = 7.0225`

So:

`2.64 < √7 < 2.65`

Because `√7 = 2.64575...`, it rounds to:

`√7 ≈ 2.65`

Keep at least one extra digit before rounding. Rounding too early can change a
later calculation.

## Estimating on a number line

The interval tells you where to place an irrational number.

`64 < 70 < 81`

Therefore:

`8 < √70 < 9`

Testing tenths gives:

- `8.3² = 68.89`
- `8.4² = 70.56`

So `√70` lies between `8.3` and `8.4`, a little closer to `8.4`.

## Comparing irrational and rational numbers

You can compare a square root with a positive decimal by squaring the decimal.

Compare `√40` and `6.3`:

`6.3² = 39.69`

Since `40 > 39.69`:

`√40 > 6.3`

This method avoids relying on a calculator display.

## Ordering several real numbers

Approximate only the values that need it.

Order `2.7`, `√8`, and `3`:

`√8 ≈ 2.83`

Therefore:

`2.7 < √8 < 3`

For negative values, remember that farther left means smaller:

`-√5 ≈ -2.24`

so:

`-√5 < -2.2`

## Other irrational numbers

Square roots of non-perfect squares are common irrational numbers, but they
are not the only ones.

`π = 3.141592...`

Useful approximations include:

- nearest whole number: `π ≈ 3`
- nearest tenth: `π ≈ 3.1`
- nearest hundredth: `π ≈ 3.14`

An approximation should match the precision requested by the problem.

## Estimating expressions

Approximate the irrational part, then complete the operation.

Estimate `2 + √6` to the nearest tenth:

`√6 ≈ 2.449...`

`2 + √6 ≈ 4.449...`

Therefore:

`2 + √6 ≈ 4.4`

For a multi-step calculation, keep extra digits until the final rounding step.

## Geometry connection

If a square has area `75 square meters`, its exact side length is:

`√75 meters`

Since `8² = 64` and `9² = 81`, the side is between `8` and `9` meters.

`√75 ≈ 8.66`

So the side is about `8.7 meters` to the nearest tenth.

The exact form and approximate form answer different questions:

- exact: `√75 m`
- nearest tenth: `8.7 m`

## Check whether an estimate is reasonable

Square a root estimate and compare it with the original radicand.

For `√20`, an estimate of `4.5` gives:

`4.5² = 20.25`

That is close to `20`, so `4.5` is a reasonable tenth-place estimate.

An estimate of `5.5` gives `30.25`, which is much too large.

## Common mistakes

- Writing `√5 = 2.24`. Rounded decimals need `≈`, not `=`.
- Looking at `30` and guessing without using nearby perfect squares.
- Rounding every intermediate value. Keep extra digits until the final answer.
- Forgetting to reverse intuition with negatives. `-3.2` is less than `-3.1`.
- Believing the decimal approximation makes the original number rational.
  `2.24` is rational, but the exact value `√5` remains irrational.
- Comparing `√40` with `6.3` by comparing `40` with `6.3`. Compare compatible
  quantities, such as `40` with `6.3²`.

## A reliable strategy

1. Identify nearby perfect squares.
2. Write whole-number bounds.
3. Square tenths or hundredths to narrow the interval.
4. Round only to the requested place.
5. Use `≈` for the rounded result.
6. Check by squaring the estimate.

## Quick practice

1. Between which integers does `√45` lie?
2. Approximate `√45` to the nearest tenth.
3. Which is greater: `√10` or `3.1`?
4. Order `√15`, `3.9`, and `4`.
5. A square has area `110 ft²`. Estimate its side length to the nearest tenth.

### Answers

1. Between `6` and `7`
2. `√45 ≈ 6.7`
3. `√10`, because `3.1² = 9.61 < 10`
4. `√15 < 3.9 < 4`
5. `√110 ≈ 10.5 ft`
