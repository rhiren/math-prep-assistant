# One Solution, No Solution, or Infinitely Many Solutions

## Big Idea

Not every equation has exactly one answer. When solving an equation, the final true or false statement tells you how many solutions it has.

## Three Outcomes

- One solution: the variable equals one value, such as `x = 5`.
- No solution: solving leads to a false statement, such as `8 = 11`.
- Infinitely many solutions: solving leads to a true statement, such as `8 = 8`.

## Worked Examples

One solution:

`3x + 4 = 19`

`3x = 15`

`x = 5`

No solution:

`2x + 7 = 2x - 3`

Subtract `2x` from both sides:

`7 = -3`

That is false, so there is no solution.

Infinitely many solutions:

`4(x + 2) = 4x + 8`

Distribute:

`4x + 8 = 4x + 8`

Both sides are the same expression, so every value of `x` works.

## What To Watch For

If the variable disappears, do not panic. Read the statement that remains. A true statement means infinitely many solutions; a false statement means no solution.

## Common Mistake

Do not write `x = 0` just because the variable cancels. The result depends on whether the remaining statement is true or false.

## Quick Self-Check

Try two different values. If both work and the simplified equation became a true identity, the equation has infinitely many solutions.
