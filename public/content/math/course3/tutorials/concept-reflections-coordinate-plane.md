# Reflections on the Coordinate Plane

## Big Idea

A reflection flips a point or figure across a line, like a mirror.

On the coordinate plane, the mirror line is often the `x`-axis or the `y`-axis. The image lands the same distance from the mirror line as the original point, but on the opposite side.

Reflections are rigid transformations. That means the figure changes position and orientation, but the side lengths and angle measures stay the same.

## What To Notice

- Reflecting across the `x`-axis changes the sign of `y`.
- Reflecting across the `y`-axis changes the sign of `x`.
- Reflecting across the origin changes both signs.
- Points on the mirror line do not move.
- The preimage and image are the same perpendicular distance from the mirror line.
- A reflected figure keeps its size and shape, but it may face the opposite direction.

## Worked Example

Reflect point `A(-3, 5)` across the `x`-axis.

The `x`-axis is horizontal, so the point flips vertically.

The `x`-coordinate stays the same:

`x = -3`

The `y`-coordinate changes sign:

`5 -> -5`

So the image is `A'(-3, -5)`.

The rule for reflecting across the `x`-axis is:

`(x, y) -> (x, -y)`

## Strategy

| Reflection | Coordinate rule | What changes |
| --- | --- | --- |
| Across the `x`-axis | `(x, y) -> (x, -y)` | only `y` changes sign |
| Across the `y`-axis | `(x, y) -> (-x, y)` | only `x` changes sign |
| Across the origin | `(x, y) -> (-x, -y)` | both signs change |

For a figure, reflect every vertex using the same rule. Then connect the image points in the same order.

## Memory Anchors

The mirror line tells you which coordinate stays the same.

Across the `x`-axis: keep `x`, change `y`.

Across the `y`-axis: keep `y`, change `x`.

If a point starts on the mirror line, its distance from the mirror line is 0, so it stays where it is.

## Common Traps

- Do not change both signs for an `x`-axis or `y`-axis reflection.
- Do not switch the coordinates unless the reflection is over the line `y = x`, which is not this lesson.
- Do not treat a reflection like a slide. A translation moves every point the same direction; a reflection flips points across a mirror line.
- Do not forget points on the axis. A point like `(4, 0)` reflected across the `y`-axis changes to `(-4, 0)`, but reflected across the `x`-axis it stays `(4, 0)`.
- Do not assume orientation stays the same. A reflected figure faces the opposite way.

## Pause And Think

Reflect `B(6, -2)` across the `y`-axis.

Across the `y`-axis, the `y`-coordinate stays the same and the `x`-coordinate changes sign.

`6 -> -6`

`-2` stays `-2`

So `B'` is `(-6, -2)`.

Now reverse it. If a point reflects across the `y`-axis to become `(-6, -2)`, then the original point was `(6, -2)`. A reflection undoes itself when you reflect over the same line again.

## Apply It

A triangle has vertices `P(1, 3)`, `Q(5, 3)`, and `R(2, 6)`. Reflect the triangle across the `x`-axis.

Use `(x, y) -> (x, -y)`:

- `P(1, 3) -> P'(1, -3)`
- `Q(5, 3) -> Q'(5, -3)`
- `R(2, 6) -> R'(2, -6)`

The triangle flips below the `x`-axis. Its side lengths and angle measures stay the same.
