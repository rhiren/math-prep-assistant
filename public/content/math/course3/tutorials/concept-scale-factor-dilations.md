# Scale Factor and Dilations

## Big Idea

A scale factor tells how many times as large or as small the image is compared with the original figure.

For a dilation, every length is multiplied by the same scale factor. If one side doubles, every side doubles. If one side is cut in half, every side is cut in half.

The scale factor is always found by comparing matching parts:

`scale factor = image length / original length`

This concept is about choosing the right comparison, using the scale factor, and knowing when to multiply or divide.

## What To Notice

- Scale factor greater than `1`: the image is larger.
- Scale factor between `0` and `1`: the image is smaller.
- Scale factor equal to `1`: the image is the same size.
- Image length = original length times scale factor.
- Original length = image length divided by scale factor.
- Perimeter changes like length, so it multiplies by the scale factor.
- Area changes by the scale factor squared.

## Worked Example

A side of a triangle is `6` units. After a dilation, the matching side is `15` units.

Find the scale factor:

`15 / 6 = 2.5`

So the scale factor is `2.5`.

If another original side is `8` units, its image length is:

`8 * 2.5 = 20`

The matching image side is `20` units.

## Working Backward

Sometimes the question gives the image and asks for the original.

If an image side is `18` units after a dilation with scale factor `3`, divide by `3`:

`18 / 3 = 6`

The original side was `6` units.

## Coordinates Still Use Scale Factor

For a dilation centered at the origin, multiply both coordinates by the scale factor.

If `A(4, -3)` is dilated by scale factor `2`, then:

`A'(8, -6)`

To check whether a point could be an image, compare the coordinate ratios. The x-ratio and y-ratio must match.

## Length, Perimeter, and Area

| Measure | How it changes under scale factor k |
| --- | --- |
| Side length | multiply by `k` |
| Perimeter | multiply by `k` |
| Area | multiply by `k^2` |

This is a common trap. If the scale factor is `3`, side lengths are `3` times as long, but area is `9` times as large.

## Common Traps

- Do not subtract original from image when finding scale factor. Divide image by original.
- Do not use original divided by image unless you are intentionally finding the reciprocal.
- Do not add the scale factor to a length. Dilations multiply.
- Do not use the length scale factor for area. Area uses the square of the scale factor.
- Do not compare parts that do not match. Use corresponding sides or corresponding coordinates.

## Pause And Think

A rectangle has perimeter `28` units and area `40` square units. It is dilated by scale factor `2`.

The new perimeter is:

`28 * 2 = 56` units

The new area is:

`40 * 2^2 = 160` square units

Perimeter and area do not change the same way.

## 3-2-1 Memory Check

3 moves:

- Find scale factor with image divided by original.
- Find image length by multiplying.
- Find original length by dividing.

2 measurements:

- Length and perimeter use `k`.
- Area uses `k^2`.

1 question to ask:

Am I comparing matching parts in the correct direction?
