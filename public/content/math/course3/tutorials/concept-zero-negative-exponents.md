# Zero and Negative Exponents

## The big idea

Exponent rules keep working when exponents reach zero or become negative.

The key is to look at a quotient pattern:

| Power | Value |
| --- | --- |
| `2³` | `8` |
| `2²` | `4` |
| `2¹` | `2` |
| `2⁰` | `1` |
| `2⁻¹` | `1/2` |
| `2⁻²` | `1/4` |

Each step divides by 2. That is why `2⁰ = 1` and negative exponents create
reciprocals.

## Zero exponents

For any nonzero base:

`a⁰ = 1`

Examples:

- `7⁰ = 1`
- `x⁰ = 1` when `x ≠ 0`
- `6a⁰ = 6 × 1 = 6`

The base must be nonzero because `0⁰` is not defined in this course.

## Negative exponents

A negative exponent does not make a number negative. It means reciprocal.

`a⁻ⁿ = 1/aⁿ` for `a ≠ 0`

Examples:

- `3⁻² = 1/3² = 1/9`
- `x⁻⁴ = 1/x⁴`
- `5x⁻² = 5/x²`

## Moving across the fraction bar

A factor with a negative exponent moves across the fraction bar and becomes
positive.

`a⁻²b³ = b³/a²`

`1/x⁻⁵ = x⁵`

Only the factor with the negative exponent moves. Coefficients stay where they
are unless they also have a negative exponent.

## Fractions with negative exponents

A negative exponent on an entire fraction takes the reciprocal first.

`(2/3)⁻² = (3/2)² = 9/4`

`(3/x)⁻² = (x/3)² = x²/9`

Parentheses matter because the exponent applies to the whole grouped expression.

## Signs and parentheses

`(-2)⁻³ = 1/(-2)³ = -1/8`

`-2⁻³ = -(2⁻³) = -1/8`

For even exponents, the difference is more visible:

`(-3)⁻² = 1/9`

`-3⁻² = -1/9`

## Strategy

1. Simplify any zero exponents on nonzero bases to `1`.
2. Move factors with negative exponents across the fraction bar.
3. Apply power rules to each base separately.
4. Keep coefficients and parentheses under control.
