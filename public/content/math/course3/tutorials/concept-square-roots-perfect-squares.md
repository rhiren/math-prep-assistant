# Square Roots and Perfect Squares

## The big idea

Squaring and taking a square root are inverse operations.

`7² = 49`, so `√49 = 7`.

A **perfect square** is the product of an integer multiplied by itself.

Examples:

- `0 = 0²`
- `1 = 1²`
- `9 = 3²`
- `64 = 8²`
- `144 = 12²`

## What a square root means

`√81` asks:

> What nonnegative number multiplied by itself equals 81?

The answer is `9`, because `9 × 9 = 81`.

The radical symbol `√` names the **principal square root**, which is
nonnegative:

`√81 = 9`, not `±9`.

## A radical versus an equation

This distinction is important:

- `√81 = 9`
- `x² = 81` has two solutions: `x = 9` and `x = -9`

Both `9²` and `(-9)²` equal `81`, but the symbol `√81` names only the
nonnegative root.

## Negative signs

Where the negative sign appears changes the meaning.

- `-√49 = -7`
- `√(-49)` is not a real number
- `(-7)² = 49`
- `-7² = -(7²) = -49`

Parentheses tell you whether the negative sign is part of the base being
squared.

## Perfect square or not?

If an integer lies between two consecutive perfect squares, it is not a
perfect square.

`49 < 60 < 64`

Since `49 = 7²` and `64 = 8²`, `60` is not a perfect square and:

`7 < √60 < 8`

The exact value `√60` is irrational. A later concept will focus on estimating
irrational roots more precisely.

## Square roots of fractions and decimals

Take the square root of the numerator and denominator when both are perfect
squares:

`√(49/64) = √49 / √64 = 7/8`

For a terminating decimal:

`√0.81 = 0.9`

because `0.9 × 0.9 = 0.81`.

## Geometry connection

The area of a square is:

`A = s²`

If a square has area `196 square centimeters`, then:

`s = √196 = 14 centimeters`

Square roots recover a side length from a square's area.

## Comparing without a calculator

To compare `√70` and `8`, compare their squares:

- `8² = 64`
- `70 > 64`

Therefore `√70 > 8`.

To locate `√115`:

- `10² = 100`
- `11² = 121`

So `10 < √115 < 11`.

## Common mistakes

- Saying `√36 = ±6`. The principal square root is `6`; an equation such as
  `x² = 36` has solutions `±6`.
- Thinking `√(a + b) = √a + √b`. For example, `√(9 + 16) = 5`, but
  `√9 + √16 = 7`.
- Forgetting that `(-5)² = 25`, while `-5² = -25`.
- Assuming every square root is irrational. Roots of perfect squares are
  integers.
- Giving square units for a side length. Area uses square units; length does
  not.

## Quick practice

1. Find `√169`.
2. Is `150` a perfect square?
3. Solve `x² = 100`.
4. Between which integers does `√90` lie?
5. A square has area `225 ft²`. Find its side length.

### Answers

1. `13`
2. No; `12² = 144` and `13² = 169`.
3. `x = 10` or `x = -10`
4. Between `9` and `10`
5. `15 ft`
