# Exterior Angles of Triangles

## Big Idea

An exterior angle of a triangle is formed when one side of the triangle is extended past a vertex.

The exterior angle has two powerful relationships:

- it forms a linear pair with the adjacent interior angle
- it equals the sum of the two remote interior angles

The remote interior angles are the two triangle angles that are not touching the exterior angle.

## What To Notice

- Adjacent interior angle + exterior angle = 180 degrees.
- Exterior angle = remote interior angle + remote interior angle.
- A remote interior angle is inside the triangle and away from the exterior angle.
- The exterior angle is always larger than either remote interior angle by itself.
- You can often solve the same problem two ways: linear pair first, or remote-angle sum first.
- Diagrams can be misleading, so rely on relationships rather than appearance.

## Worked Example

A triangle has remote interior angles of 47 degrees and 68 degrees.

The exterior angle is:

47 + 68 = 115

So the exterior angle is 115 degrees.

The adjacent interior angle forms a linear pair with the exterior angle:

180 - 115 = 65

Check the triangle interior angles:

47 + 68 + 65 = 180

Both relationships agree.

## Strategy

| Given information | Best first move |
| --- | --- |
| Two remote interior angles | Add them to find the exterior angle |
| Exterior angle and one remote interior angle | Subtract to find the other remote angle |
| Adjacent interior angle | Subtract from 180 to find the exterior angle |
| Exterior angle and adjacent interior angle | Check that they add to 180 |
| Algebra expressions | Set exterior angle equal to the remote-angle sum |
| Ratio between remote angles | Use the exterior angle as the total for the ratio |

## Memory Anchors

The exterior angle looks outside the triangle, but it tells you something about the two inside angles far away from it.

Remote means not touching the exterior angle.

Two equations matter most:

- exterior = remote + remote
- exterior + adjacent interior = 180

## Common Traps

- Do not add the exterior angle to the two remote angles and set that equal to 180.
- Do not use the adjacent interior angle as one of the remote interior angles.
- Do not assume the exterior angle equals just one remote interior angle.
- Do not forget that the exterior and adjacent interior angle form a straight line.
- Do not trust a diagram that is not drawn to scale.
- Do not stop after solving for x; check whether the question asks for x or an angle measure.

## Pause And Think

A student sees remote interior angles of 39 degrees and 74 degrees and writes:

x + 39 + 74 = 180

That equation treats x like the third interior angle, not the exterior angle.

For the exterior angle, use:

x = 39 + 74

x = 113

The adjacent interior angle would be 180 - 113 = 67 degrees.

## Apply It

Suppose an exterior angle is 128 degrees, and one remote interior angle is 52 degrees.

Use the exterior angle theorem:

52 + missing remote angle = 128

missing remote angle = 76

Then check the adjacent interior angle:

180 - 128 = 52

The triangle's interior angles are 52 degrees, 76 degrees, and 52 degrees. They add to 180.

## 3-2-1 Memory Check

3 angle roles:

- exterior angle
- adjacent interior angle
- remote interior angles

2 relationships:

- exterior = remote + remote
- exterior + adjacent interior = 180

1 habit:

Name the angle roles before choosing an equation.
