# Para Empezar Practice Test

## Hook

This practice test is built from the first Spanish class packet: greetings, classroom phrases, classroom objects, months, numbers, and the short reading about Esteban from Guatemala.

## Big Idea

Early Spanish practice is about recognizing useful chunks and using context. You do not need to translate every word perfectly to understand the main idea.

Memory anchor: **Known words plus context help you understand.**

## Learn It

Focus areas from the packet:

| Topic | Examples |
|---|---|
| Greetings | buenos días, buenas tardes, hola |
| How someone is | ¿Cómo estás?, ¿Qué tal?, bien, regular |
| Goodbyes | adiós, hasta luego, hasta mañana |
| Classroom words | el bolígrafo, la carpeta, el cuaderno, el lápiz |
| Useful words | hay, en, por favor, ¿cuántos? |
| Numbers | uno through treinta |
| Months | enero through diciembre |
| Reading phrases | vive, tiene, le gusta, hace, yo soy de |

## Build The Model

When you see a short Spanish sentence, try this:

`known word -> sentence clue -> best meaning`

Example:

`Esteban vive en San Pedro La Laguna.`

Known words:

- Esteban = a person
- vive = lives
- en = in

Best meaning: Esteban lives in San Pedro La Laguna.

## Memory Anchors

- **¿Cómo te llamas?** asks for a name.
- **Me llamo...** gives a name.
- **Hay** means there is or there are.
- **Tiene** means has.
- **Le gusta** means he or she likes.
- **Hace** means makes.

## Common Traps

- Trap: Mixing up `buenos días`, `buenas tardes`, and `buenas noches`.  
  Fix: Match them to morning, afternoon, and evening.
- Trap: Reading `le gusta` as "I like."  
  Fix: In this packet, `le gusta` means he or she likes.
- Trap: Forgetting that `hay` can mean both "there is" and "there are."  
  Fix: Use the rest of the sentence for singular or plural meaning.

## Pause And Think

- How do you ask someone's name?
- What does `vive` mean?
- What does `el cuaderno` mean?
- Which month is `agosto`?

## Apply It

Read this mini-version of the story:

`Hay un chico. Se llama Esteban. Esteban es de Guatemala. Vive cerca del lago Atitlán. Tiene tres hermanas. A Esteban le gusta el lago.`

Now ask:

- Who is the story about?
- Where is he from?
- What does he like?
