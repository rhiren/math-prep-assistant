# Likes and Dislikes with Gustar

## Hook

In Spanish, saying "I like music" uses a different pattern from English. You say `Me gusta la música`, which is closer to "Music is pleasing to me."

## Big Idea

`Gustar` does not behave like a regular "I like" verb. Beginners should learn useful chunks first: `me gusta`, `no me gusta`, and `¿te gusta?`

Memory anchor: **The thing liked controls gusta or gustan.**

## Learn It

Useful preference phrases:

| Spanish | English |
|---|---|
| Me gusta... | I like... |
| No me gusta... | I do not like... |
| ¿Te gusta...? | Do you like...? |
| Me gusta mucho... | I like... a lot. |

Use `gusta` for one thing or an activity:

- Me gusta el arte.
- Me gusta estudiar.

Use `gustan` for more than one thing:

- Me gustan las matemáticas.
- Me gustan los deportes.

## Build The Model

Use this preference pattern:

`person affected -> gusta/gustan -> thing liked`

Example:

`Me -> gusta -> la música.`

## Memory Anchors

- **Me gusta** means I like.
- **No me gusta** means I do not like.
- **¿Te gusta?** asks do you like.
- **Plural things often use gustan.**

## Common Traps

- Trap: Saying `yo gusto` for "I like."  
  Fix: Use `me gusta`.
- Trap: Using `gusta` for several things.  
  Fix: Use `gustan` for plural nouns.
- Trap: Forgetting `no` for dislikes.  
  Fix: Put `no` before `me gusta`.

## Pause And Think

- What does `Me gusta la música` mean?
- When would you use `gustan`?
- How do you ask a classmate if they like science?

## Apply It

Create three preference sentences:

- Me gusta ____.
- No me gusta ____.
- ¿Te gusta ____?
